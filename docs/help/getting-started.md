# Getting started

## Sign in and choose a workspace

Use the canonical Loop URL for your environment:

- Development: `https://loop-dev.twiniti.ai/sign-in`
- Production: `https://loop.twiniti.ai/sign-in`

Loop uses one public URL. You do not need to choose a regional hostname. New
workspaces select their country during signup; Loop assigns the workspace to
the corresponding US, EU, or UK data service. If you are a Super Admin, open
**Super Admin**, select a workspace, and choose **Open workspace** before using
CRM pages.

The Render landing-site address is for marketing pages only. If a direct
`onrender.com/sign-in` link returns Not Found, return to the canonical Loop URL.

## Create your first records

Use **Companies** to create a company with a name, domain, and industry. Use **Contacts** to add a person with an email address and optional identity fields. You can also use **Import** when the data already exists in CSV files.

## Understand the sidebar

**Overview** shows contact, segment, and campaign totals. **Contacts** and **Companies** hold CRM records. **Segments** define audiences. **Campaigns**, **Forms**, and **Workflows** support marketing execution. **Agents** manages machine credentials, **Deliverability** shows email health, and **Settings** manages people and email tracking.

## Sign out

Choose **Sign out** at the bottom of the sidebar. Close or switch browser profiles if you are using more than one company account.
