# Campaigns

## Create a draft

Open **Campaigns**, enter a campaign name and subject, and write the HTML body. Personalization tokens supported by the current starter template include `{{firstName}}`. Select **Create draft**.

## Review and send

Use **Preview** to inspect the campaign. Select **Request approval** when it is ready for review. An authorized user can then select **Approve** and, only after confirming the audience and content, **Send**.

Sending depends on configured email and deliverability services. If a send fails, check the campaign status and the Deliverability page before retrying.
