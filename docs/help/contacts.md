# Contacts and custom properties

## Find a contact

Open **Contacts** and search by name, email, phone, or associated company. Select a contact to open its detail page. The detail page shows core information, custom fields, email activity, and change history.

## Add or edit a contact

Use **New contact**, enter the email and available identity fields, then save. From a contact detail page choose the edit controls to change core fields or grouped custom fields. If another user edits the same record first, reload and resolve the reported version conflict before saving again.

## Manage custom properties

The property manager on the Contacts page lets admins create, search, edit, and group tenant-specific fields. Give each property a readable label and a stable internal name. Choose the data type and, where applicable, define allowed options.

Deleting a property is destructive to the current contact values. Review the impact report before confirming. Historical property-change records are retained, but the property key is removed from organization contacts.

## Archive records

Archive a contact when it should no longer be active but its history must remain available. Archived records are excluded from normal active work without erasing their history.
