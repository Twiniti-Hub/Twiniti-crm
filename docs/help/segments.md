# Segments

Segments are reusable audiences based on contact fields. Open **Segments**, enter a name, choose a field, operator, and value, then select **Create segment**.

Supported operators in the current UI are **equals**, **not equals**, and **contains**. Standard fields include email, lifecycle stage, first name, and last name. Tenant custom properties are also available after they have been defined or imported.

Review the resulting filter shown in the table. Use clear, stable names such as `Active trial users` or `UK leads` so campaigns and forms remain understandable to teammates.
